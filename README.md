# 学生成绩管理系统

> Python 课程项目 —— 面向对象思想 + 数据持久化 + 数据可视化

## 项目简介

一个控制台成绩管理系统，支持学生成绩的录入、修改、删除、查询、排序与统计，
并将数据持久化到本地 JSON 文件，同时用 Matplotlib 绘制成绩分布直方图。

项目综合运用了循环与选择结构、列表与字典、文件处理、面向对象、异常处理与第三方模块。

## 功能特性

- **面向对象建模**：以 `Student` 封装单个学生实体（学号、姓名、成绩），提供 `to_dict` / `from_dict` 序列化方法；
  以 `StudentManager` 统一管理学生集合与各项业务操作。
- **成绩录入**：按学号添加学生，自动校验学号是否重复、成绩是否在 0–100 区间。
- **查询与维护**：按学号查询、删除学生、修改成绩，均给出明确的中文提示。
- **排序统计**：按成绩排序（支持升序 / 降序），输出总人数、平均分、最高分、最低分等指标。
- **数据持久化**：使用 JSON 文件保存数据，程序重启后自动加载；文件缺失或格式损坏时降级为空列表并给出提示，不中断运行。
- **可视化**：调用 Matplotlib 绘制成绩分布直方图，直观呈现成绩分布情况。

## 技术要点

| 主题 | 实现方式 |
| --- | --- |
| 面向对象 | `Student` 实体类 + `StudentManager` 管理类，静态方法 `from_dict` 负责反序列化 |
| 数据持久化 | `json` 模块读写本地文件，异常捕获保证健壮性 |
| 数据可视化 | `matplotlib.pyplot` 绘制成绩分布直方图 |
| 异常处理 | 对文件读写、格式解析等场景做 `try / except` 兜底 |

## 运行方式

依赖第三方库 `matplotlib`：

```bash
pip install matplotlib
python src/main.py
```

运行后按菜单提示操作即可，成绩数据默认保存在同目录下的 `students.json` 文件中。
